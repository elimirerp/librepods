API: application singleton AppleAccountBackend.get(context), inert constructor.
StateFlow<AppleAccountStatus>; suspend prepare, signIn, requestCode, submitCode, restore, signOut, fetchTerms, acceptTerms.
One dedicated worker serializes native and Python state. prepare explicitly invoked after Connect; no cold-start provisioning.
Real pinned FindMy.py GrandSlam SRP + trusted-device/SMS2FA, local Anisette via native Android Apple Music ADI.
No remote Anisette fallback. Saved machine/profile/serial/uid/devid checked against restored token state.
Password is removed when login completes; finished account reconstructed with password=None.
Only LOGGED_IN state exportable; incomplete 2FA/terms remains in memory.
The pinned synchronous wrapper's close() is async: explicitly awaited on wrapper's owned event loop, GC hook detached, loop closed.
Encrypted versioned AES256GCM session uses AndroidKeyStore, fresh12byte IV,128bit tag, app/version AAD.
All token blob/identity/ADI state/guards are in noBackupFilesDir. Decrypt never replaces missing key.
API errors do not expose repr/exception messages/raw Apple bodies/credentials/tokens. No added account logging.
Signout deletes local session and closes account while preserving native install identity and provisioning.
Restore is offline; signed_in restored means parsed bound session, not independently verified token validity.
New auth is required when token reauthentication needs the absent password; no promise of permanent automatic session refresh.
